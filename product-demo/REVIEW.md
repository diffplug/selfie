# Review notes

For whoever changes this film next, including an agent.

- **Real:** every screen is a screenshot of the real app in a state it really reached, running on an M4 MacBook Air against this repository's Storybook, in a throwaway clone: `selfie review`, the 124 changed, the 48 spacing-only, 85,143 pixels down to 13, the note, the reply, and the final review. Every terminal line is from those runs. GitHub and `hackathon.selfie.dev` are the live public pages, read only, for the real `main` commit, which isn't the commit in the story.
- **Staged:** the bug. The agent's change was written to hard-code a light color, so that dark mode would break. The request, the fix, and the reply were written for the film too, though each really ran.
- **Added on top:** the pointer, the camera moves, and the callouts. The render log is sped up, and ends on what it really took. JSON is trimmed, with `…` where it is. The note's typing is uncovered from its finished screenshot.
- **Timing:** scenes, subtitles, and beats come from the word times ElevenLabs gave for this take.
- **Not checked:** the sound was measured, not heard.
- **Kept warnings:** `timeline_track_too_dense`, one clip per subtitle; `dead_stretch`, judged against freeze detection on the rendered file.
